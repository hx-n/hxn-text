Fonts, text shaping, glyph masks and revisioned atlas data for Haxe. The Haxelib contains generated bindings and prebuilt native libraries for desktop, mobile, Ash wasm and Emscripten. Haxe consumers do not need Rust.

Font assets use the normal hxn-assets annotations and loader with FontAssets.decode/load. The included example loads a content-addressed bundled font, prepares text and retains its font license. Applications own drawing and GPU resources.
